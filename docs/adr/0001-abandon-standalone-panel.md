# ADR-0001: 废弃自建独立面板，改用上游内置 Dashboard

日期：2026-09-25 ｜ 状态：已接受

## 背景

早期上游 Go 引擎没有管理界面，为在 Android 上可视化管理，自建了独立面板进程
`panel-9router`（Go 后端 + 自制前端，端口 20129，bcrypt 登录，直接读写引擎的
sqlite 库），并衍生出契约提取、备份自检等一整套工程。

## 决策

上游 v1.9.1 已内置完整官方 Dashboard（Svelte SPA，`go:embed` 进引擎二进制，
含登录、供应商、密钥、组合、用量等功能），功能覆盖自建面板的核心诉求。
**彻底废弃自建面板**：新模块不含任何面板进程，Dashboard 由引擎直接服务。

## 后果

- 正面：少一个常驻进程与端口；少一套需与引擎 schema 同步的契约代码；
  每次上游同步零面板维护成本。
- 负面：自建面板独有的 DNS 管理页随面板一起废弃 → 由模块 WebUI 承接
  （见 ADR-0002）；官方 Dashboard 未覆盖的能力（若有）只能等上游或另立模块层方案。
- 旧资产：`9router-magisk/`、`9RouterGo-Magisk-old/`、根目录三份旧文档在
  新版真机验证通过后删除。
